- D-015 (10/31/2026, lab decision within D-011): Testimony likelihoods use an interval with soft edges whose width is the claim's own uncertainty band, but never narrower than 25 percent of the claimed value (log-scale claims: log10(1.25)), because these are recollections, often years later. Conflicting claims each enter with their own interval. H-WIT ("object at the aircrew's range") is redefined as an object on a free smooth path with a free range, so testimony is applied to every hypothesis identically and is not counted twice. Stewart may change the floor.
- D-016 (10/31/2026, lab decision within the scoring design): The apparent-size criterion applies only when the object is resolved (blob major axis at least 3 times the point-spread width measured on the same video); for unresolved objects (a few pixels), thresholded size tracks brightness for any source, so the criterion is reported but carries no weight for any hypothesis. The display rounding convention for whole-degree readouts (round vs truncate toward minus infinity) is a sensor-model setting fitted once per video and shared by every hypothesis, never a per-hypothesis parameter.
- D-017 (owner ruling, 11/01/2026, answers Q-007): At GIMBAL's 0.7 deg field of view, where the object counts as resolved but its size comes from a saturated (clipped) blob, the size criterion is reported but carries weight 0 for every hypothesis, the same treatment as brightness. Stewart: "we can always change later."

Methods stated in `docs/results/REVIEW-M3.md` section 7.
