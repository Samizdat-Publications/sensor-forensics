# Model recovery (M3.4): which hypotheses can this data separate?

Generated by `python -m solve.recovery --report` from `data/derived/<case>/recovery.csv` (written by `python -m solve.recovery <case> <variant>`). Design: `docs/design/scoring.md` (binding): a model-recovery test, synthetic data from each hypothesis through the full scorer, shows which hypotheses the data can separate even in principle.

**Method.** For each hypothesis, synthetic observations were generated at three parameter sets: its physics-only best fit to the real data, and its best fit with the range held at about 0.6 and 1.6 times that (pulled toward 1 where a constraint would break). Each synthetic data set has the real sampling and sensor behavior: whole-degree az / el readouts with the case's display rounding on the 6-frame display updates, the 0.1 nmi and 10 kt range and Vc steps (GOFAST), the real measurement noise of every image series (its own residual, circularly shifted, so its scatter, tails and autocorrelation are kept), and the same weight-0 criteria as the real case. Every hypothesis was then fitted to every data set by the single scoring path (physics-only total, the real runs' fit settings, the same for all; the generating model's total at its true parameters is kept as a check on the optimizer). A modest number of noise draws per set: enough to show the pattern, not to estimate rates.

Margins are differences of physics-only totals (log-likelihood after the complexity penalty); 2.3 is a likelihood ratio of 10.

## Limits

- Few trials per cell: a 1 in a cell is an existence proof that the pair can be confused, not a rate.
- The synthetic data are drawn from each hypothesis's own model, so this tests separability under the lab's sensor model; errors in that model (shared by every hypothesis) are not tested here.
- Testimony is not part of this test (physics-only total).
- GIMBAL at 0.7 deg is scored with the apparent-size criterion at weight 0 (D-017: the blob is resolved but saturated), the same as the real 0.7 deg run, so its weighted criteria are the same kinds as at 0.35 deg; the two fields of view differ through the jet's path (turn rate) and the point-spread width, not through which criteria count.
