## Accomplished

- **Case files.** The UFO Case File format v0.1 (`schemas/ufo-case-file.schema.json`, JSON Schema 2020-12, plain-words guide in `schemas/README.md`, D-014). `tools/export_cases.py` writes four cases from the final results: `exports/cases/gimbal.json`, `gofast.json`, `flir1.json` and `pursue-triage.json`; `tools/validate_cases.py` checks them.
- **Verdicts in the case files follow one rule for every case.** A lead is called decisive only if it is a likelihood ratio of 10 or more AND none of these change it: a refit without the post-hoc data-quality exclusions, the rotation noise within a factor of 2 of the value measured from the data, and the model-recovery test (data made by another explanation also won by the leader). Under that rule no Navy video has a decisive leader, and each case file says why in its `verdict.conditions`.
- **README for a non-programmer** (`README.md`): what was found in plain words, how to open the app, what each of the five views shows, how to read a range curve, one-line Windows PowerShell 5.1 commands with full paths to rebuild everything, where things are, and credits.
- **2-minute highlight recording** (`artifacts/movies/highlights_2min.mp4`, `tools/record_highlights.py`): a captioned tour of all five views across GIMBAL, GOFAST and FLIR1, captured with the same frame-exact method as the CP-05 recording.

- Fixed after the independent check (`artifacts/review/CP-07-review.md`): three captions and two README findings no longer claim more than the results pages (GIMBAL's 15 nmi floor holds at 0.35 deg only; GOFAST's wind measurement separates only some pairs, and the glare model leads without the size exclusion; Peings and von Rennenkampff 2023 reproduces only in part); every README command now uses full paths for Python, scripts and files (checked in Windows PowerShell 5.1). The recording was reassembled with the new captions.
